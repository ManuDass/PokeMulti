Download **PokeMulti-Setup.exe**, run the wizard, choose an install folder, and
launch PokéMulti from the installed shortcut. No development tools are needed.

- Cleaner launcher header with a compact username **Edit** control.
- Change your online name without changing your in-game name or progress.
- Install future releases through **Update program** in the launcher.
- Cleaner public source layout and documentation; local test launchers are
  excluded from the download.

Windows 10/11 x64. No ROM included: supply your own supported English FireRed
US 1.0 or 1.1 .gba or ZIP. The versioned ZIP is an optional portable package;
GitHub's source-code ZIP is not a ready-to-run download.

Existing worlds and trainer identities are preserved. Close other sessions
before updating. Experimental, noncommercial build; see the included validation
and dependency notices. Mac downloads are being tested separately.
