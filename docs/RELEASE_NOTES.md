Download **PokeMulti-Setup.exe** and run the installation wizard. Existing Windows
installations can use **Update program → Check for updates → Download & restart**.

- Send-out uses the four populated top-row animation cells; return uses only
  the three populated bottom-row cells. Each frame replaces the previous cell.
- Shiny Pokemon now use their supplied shiny sprites in grass, as followers,
  around camp and when released. Visible encounters retain their shiny identity.
- Followers appear without taking a first step and remain consistent across
  connected towns and routes. Send-out, recall, settings changes and fainted-lead
  replacements use the supplied animation sheets.
- Face your follower and press **X** for a cry, native dialogue and an animated
  reaction. Emotes, send-out and recall effects use crisp nearest-neighbor sampling at half source size.
- Usernames, party icons and other world overlays no longer flash over black
  building-transition frames.
- **Saving is manual.** The host's **Enter → Save** saves the room's trainers.
  Periodic, campaign, wager and release-triggered game saves are removed, including
  the periodic save calls responsible for hosting pauses. Save before leaving;
  **Exit world** does not start a save.

Everyone in a room must update to **FRMP 21**. Existing saves remain compatible;
rooms still require matching game and ROM revisions.

Windows 10/11 x64. **No ROM included:** supply your own unmodified English
FireRed or LeafGreen US 1.0/1.1 ROM, as GBA or ZIP. The versioned ZIP is an optional
portable package; GitHub's source ZIP is not an installed program. Mac previews
are distributed separately.
