Download **PokeMulti-Setup.exe**, run the wizard, choose an install folder, and
launch PokéMulti from the installed shortcut. Existing installations can use
**Update program → Check for updates → Download & restart**.

- **Switch ROMs without changing your username.** Settings & ROM → Change ROM
  now opens an **Update ROM** confirmation. Your identity and friends stay in place.
- **Separate world lists.** Only worlds for the selected game and exact ROM
  revision appear. Switching back restores that cartridge's world list.
- **LeafGreen's green theme** now covers launcher buttons, headings, the top
  bar, and the in-game controls. FireRed keeps its red theme. Supplied art is unchanged.
- **Host-controlled shiny rates:** Options → World lets the host choose from
  1 in 8,192 (the original game default) to 1 in 1. Changes apply during play,
  synchronize to guests, and are saved with that world. Existing Pokémon keep
  their traits; see the included multiplayer notes for generation details.
- Additional ROM-call validation covers the shared Viridian story refresh.

Everyone in a room must update: this release uses **FRMP 20**. Matching game and
ROM revisions are still required. Close other sessions before installing.

Windows 10/11 x64. **No ROM included:** supply your own supported, unmodified
English FireRed or LeafGreen US 1.0/1.1 ROM, as GBA or ZIP. The versioned ZIP is an
optional portable package; GitHub's source-code ZIP is not an installed program.
Experimental, noncommercial build. Mac previews are distributed separately.
