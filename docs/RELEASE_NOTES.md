Download **PokeMulti-Setup.exe**, run the wizard, choose an install folder, and
launch PokéMulti from the installed shortcut. No development tools are needed.

- Load **LeafGreen** from a `.gba` file or ZIP, with a green cartridge and the
  supplied LeafGreen label artwork.
- Switch games using **Settings & ROM → Change ROM**. Each ROM keeps its own
  world list; existing worlds and trainer identities are preserved.
- Game hooks now use separate verified mappings for FireRed and LeafGreen
  US v1.0/v1.1, including late-code offsets in FireRed v1.1.
- Rooms require the **same game and ROM revision**. A mismatch explains what to
  change before any trainer save is downloaded.
- Wrong room keys and full rooms also return clear messages to the launcher.

Windows 10/11 x64. **No ROM included:** supply your own supported, unmodified
English FireRed or LeafGreen ROM. The versioned ZIP is an optional portable
package; GitHub's source-code ZIP is not a ready-to-run download.

Existing installations can use **Update program → Check for updates**. Close
other sessions before installing. Experimental, noncommercial build; see the
included validation and dependency notices. Mac builds are tested separately.
