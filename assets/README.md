# Runtime artwork

Only artwork used by the application is tracked here. Files keep their original
pixels and geometry. `cmake/Assets.cmake` maps this source layout to the runtime's
installed paths.

| Folder | Used for |
| --- | --- |
| `camp` | Three original tent animation frames |
| `cartridge` | Launcher cartridge label |
| `chat` | Original 16×16 chat bubble tiles |
| `controller` | Poké Ball Plus preview model and texture |
| `credits` | Supplied follower attribution |
| `followers` | 386 directional follower sheets |
| `fonts` | Fonts used by the launcher, game frame and labels |
| `ui` | Original application, party and Egg icons |

Full reference packs, unused variants and generated ROM artwork are not included.
See [asset provenance](../docs/UI_ASSETS.md) and
[dependency notices](../docs/THIRD_PARTY.md).
